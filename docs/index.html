Thematic 0.10.6 · User manual

From sources to a traceable synthesis.

This manual follows a complete research workflow: create a project, bring in PDF and Markdown sources, capture evidence, organize themes, test claims, and assemble a draft that remains linked to its sources.

01

Installation

Install Thematic on Windows, macOS, or Linux, then optionally open the prepared example project.

Open the latest Thematic release, expand its Assets list, and select your platform below. Checking the SHA-256 value in the release notes is optional, but it can confirm that a download is complete and unchanged. The automatically generated source-code archives are not installers.

Windows x64

  1. Download Thematic_0.10.6_x64-setup.exe.
  2. Optionally verify it in PowerShell with Get-FileHash .\Thematic_0.10.6_x64-setup.exe -Algorithm SHA256.
  3. Run the installer, follow the setup prompts, and launch Thematic from its installed shortcut.
Unsigned installer

Windows Defender SmartScreen may identify the publisher as unknown because this installer is not currently code-signed. Only use an installer downloaded from the official repository.

macOS

  1. Download Thematic_0.10.6_aarch64.dmg for an Apple silicon Mac, or Thematic_0.10.6_x64.dmg for an Intel Mac.
  2. Optionally verify it in Terminal with shasum -a 256 <downloaded-file.dmg>.
  3. Open the disk image, drag Thematic to Applications, and launch it from there.
Not Apple-notarized

The macOS packages are ad-hoc signed but not Apple-notarized. If macOS blocks the first launch, approve Thematic under System Settings > Privacy & Security, then open it again.

Debian or Ubuntu x64

  1. Download Thematic_0.10.6_amd64.deb.
  2. Optionally verify it with sha256sum Thematic_0.10.6_amd64.deb.
  3. In the download folder, run sudo apt install ./Thematic_0.10.6_amd64.deb, then launch Thematic from the application menu.

AppImage for compatible Linux x64 systems

  1. Download Thematic_0.10.6_amd64.AppImage.
  2. Optionally verify it with sha256sum Thematic_0.10.6_amd64.AppImage.
  3. Make it executable with chmod +x Thematic_0.10.6_amd64.AppImage.
  4. Launch it with ./Thematic_0.10.6_amd64.AppImage.

Optional example project

The release also includes Nature-in-Everyday-Life--What-Helps-Mental-Well-Being-.thematic. It is a separate, optional download containing a populated research workspace. It is useful for exploring the application before creating your own project.

  1. Download the .thematic example from the same release.
  2. Launch Thematic and select the folder button beside Current project.
  3. Select Import .thematic project, choose the downloaded file, inspect the preview, and import it as a new project.
Portable bundles can contain documents.

A .thematic file can include copies of its source PDFs and Markdown files. Review a bundle before sharing it outside its intended audience.

02

Quick start

Create a useful project without designing a complete coding scheme in advance.

  1. Create a blank project. Open Manage projects, enter a concise name under Create another project, and select Create project.
  2. Add one or two sources. Select Add sources and choose One or more files. Starting small makes the interface easier to learn.
  3. Capture a meaningful passage. Open a document in Reader, leave the Text tool selected, highlight a passage, add an optional note, and select Save excerpt.
  4. Create a broad theme. Open Themes, select New theme, and name a pattern that has begun to appear. Add more specific themes later.
  5. Save a checkpoint. Select Save or press Ctrl + S. This flushes current changes and creates a recovery point.
A low-friction first session

Use one project, two documents, three excerpts, and one broad theme. Once that loop feels natural, add screening, extraction, claims, and drafting.

Switch projects and move among Reader, Themes, and Synthesis from the top bar.

2Library

Browse indexed folders, virtual groups, PDFs, Markdown files, and source metadata.

4Excerpt panel

Review selected text or images, write a note, choose colors, and attach themes.

5Project actions

Add sources, save a checkpoint, export data, open settings, or use the Support Center.

6Command palette

Press Ctrl + K to search common navigation and project actions.

04

Projects and sources

Keep separate investigations independent while reusing the same application.

Create and switch projects

Select the folder button beside Current project to open the Project manager. From there you can create, open, rename, export, repair, or remove a project. Creating a project selects it immediately. The drop-down beside Current project is the fastest way to switch among existing projects.

Removing a project does not delete the original PDFs or Markdown files.

It removes that project's catalogue records from Thematic. Export a portable copy first if you may need its annotations or synthesis state later.

Add sources

Folder

Indexes every supported PDF and Markdown file inside the selected folder. Use this for an established literature folder or corpus.

One or more files

Adds only the selected PDFs, Markdown files, or mixed selection. Use this for a focused reading queue.

Use Add sources in the header or at the bottom of the Library. Thematic indexes the files and keeps their source paths; it does not rewrite the originals. Use the Library's Rescan action after adding or removing files in an indexed folder.

Organize the Library

  • Use the search field to narrow documents by title or metadata.
  • Filter by physical source folder or create virtual directories for your own working structure.
  • Move a document into a virtual directory without moving its original file on disk.
  • If a source file was moved, use its relink action to point the catalogue record to the new location.

Import an existing project

In Project manager, select Import .thematic project. The preview reports document records, bundled files, excerpts, themes, graph state, screening records, extractions, claims, draft sections, and recovery checkpoints. Resolve any reported file conflicts before selecting Import as new project.

05

Reader and excerpts

Capture evidence without losing the document, page, location, note, or analytic context that gives it meaning.

Read and navigate

Select a document in the Library to open it in the center panel. PDF sources retain page locations; Markdown sources use document headings or text locators. Use the viewer controls to zoom, move through pages, and switch among the text-selection, image-region, and copy tools.

Capture a text excerpt

  1. Select the Text tool. It is the default highlighting mode.
  2. Select a passage. Drag over text in the document, or make a selection and press Ctrl + Enter.
  3. Record why it matters. Add a plain-text or Markdown + KaTeX research note; a note is optional.
  4. Classify only when useful. Choose a highlight color and attach zero, one, or several existing themes.
  5. Save the excerpt. Select Save excerpt, or use Ctrl + Enter when quick capture is enabled.

Capture an image region from a PDF

Select the Image tool and drag a rectangle over one PDF page. Review the captured region in the excerpt editor, add a note and themes if needed, then save it. Image excerpts remain visible as thumbnails in the Reader, Theme Atlas, claim evidence, and supported exports.

Review and revise excerpts

  • Select an excerpt card to edit its note, format, themes, or highlight color.
  • Use Find in document to return to the excerpt's saved location.
  • Use Redefine Selection to replace the captured area while retaining its note, themes, and color.
  • Press Esc to cancel an active selection.
Write analytic notes, not summaries alone.

A useful note records why the excerpt matters, what it supports or challenges, and which question it raises for the next reading pass.

06

Metadata and citations

Keep the bibliographic record beside every excerpt so evidence remains attributable.

Edit a document record

Open a document and select its record-edit action. The Edit document record window supports journal articles, books, chapters, theses or dissertations, reports, web sources, and other materials. You can record a citation key, title, authors, publication date, DOI, journal or source, publisher, volume, issue, pages, URL, and abstract.

To reuse an existing reference-manager record, paste a BibTeX or BibLaTeX entry and select Parse entry. Review the populated fields before saving. The local source path is shown for context but the original document is never changed.

Optional metadata lookup

In Settings, you can enable citation lookup after import. For PDFs, Thematic can detect an explicit DOI and use online DOI and Crossref services to fill matching bibliographic fields. Documents without a verified match remain unchanged. A Crossref contact email is optional and is sent only with those metadata requests.

Verify imported metadata.

Check author order, dates, page ranges, capitalization, and source type against the document before relying on a generated citation.

Copy a citation

Select the document's citation action and choose one of four outputs:

In-text citation

A concise author-date form for use while drafting.

Bibliography

A formatted bibliography entry based on the current document record.

BibLaTeX / Biber

A structured entry for BibLaTeX workflows.

BibTeX

A compatible entry for traditional BibTeX workflows.

07

Themes and the atlas

Move between a conceptual hierarchy and a visual map of themes, excerpts, documents, and analytic notes.

Create a theme

  1. Open Themes. Select Themes in the main navigation or press Ctrl + 2.
  2. Select New theme. Give the theme a specific, recognizable name.
  3. Describe its boundary. Use the description to record what belongs in the theme and what does not.
  4. Choose its place. Leave Parent theme empty for a top-level theme, or choose a parent and explain the relationship.
  5. Choose a color and save. Color helps scan the atlas but should not replace a clear name and description.

Connect evidence and concepts

Assign themes to excerpts from the Reader, or inspect and edit connections from the Theme Atlas. Select Connect nodes, choose the first node, then the second. Relationships can be labeled so the graph records the analytic meaning of a connection rather than only its existence.

  • Theme-to-excerpt connections show which evidence was coded to a concept.
  • Theme-to-theme connections can express parent relationships or other conceptual links.
  • Excerpt-to-excerpt relationships can record comparison, contradiction, sequence, or another explicit connection.
  • Graph notes provide movable analytic annotations that are not forced into the theme hierarchy.

Arrange and filter the graph

Drag nodes to create a useful working arrangement. Use auto-layout when the graph becomes crowded, or choose another default layout in Settings: relationship map, organic clusters, hierarchy, radial focus, or compact tree. Search and filters can narrow the graph by project, theme, document, or matching text. Label visibility, node scale, node shapes, and zoom can also be adjusted.

Graph view

Best for relationships, clusters, comparison, and spatial working arrangements.

List view

Best for reviewing the hierarchy and reading excerpts grouped under their themes.

Useful atlas shortcuts

  • Ctrl + Shift + R re-centers the graph.
  • Ctrl + Shift + L applies auto-layout.
  • Ctrl + Shift + Z toggles graph Zen mode.
  • Ctrl + Shift + N adds a graph note.
08

Research synthesis

Turn a coded reading collection into a review protocol, structured evidence, claims, and a source-linked draft.

Open Synthesis from the main navigation or press Ctrl + 3. The six tabs form a suggested progression, but they are not a locked sequence. Use only the stages that fit your method.

01 PROTOCOLDefine the review

Record the research question, scope and context, inclusion criteria, and exclusion criteria.

02 SCREENINGDecide what belongs

Mark sources as inbox, to read, included, or excluded; add priorities, reasons, and notes.

03 EXTRACTIONCompare consistently

Define reusable text, number, yes/no, date, or category fields and complete them for included sources.

04 CLAIMSTest propositions

State a claim, record confidence and status, and link supporting, qualifying, or contradicting excerpts.

05 DRAFTAssemble the argument

Create and reorder sections, write in Markdown + KaTeX, attach claims, and add source excerpts from the shelf.

06 HEALTHFind gaps

Review missing decisions, metadata gaps, unthemed excerpts, unsupported claims, and orphaned records.

1. Write the protocol

Start with a focused research question. Use Scope and context for population, time frame, setting, or conceptual boundaries. Write inclusion and exclusion criteria as decisions another person could apply consistently. These fields support Markdown and KaTeX.

2. Screen sources

Search or filter the source list, then record a status, priority, exclusion reason when relevant, and a screening note. Select multiple visible records to apply batch decisions such as Include, Exclude, To read, or High priority. Use the source-opening action whenever the decision requires full-text review.

3. Define an extraction schema

Add fields that every included source should answer, such as sample size, study design, location, intervention, or core finding. Select a source, complete each field, and use its linked excerpts as evidence. A small, stable schema usually produces cleaner comparisons than a large schema that changes mid-review.

4. Build evidence-backed claims

A claim is more than a theme: it is a proposition that can be supported, qualified, or contradicted. Give the claim a status and confidence value, attach relevant themes, and link excerpts with an explicit evidence role. Review the detailed excerpt context before deciding what role it plays.

5. Draft beside the evidence

Create sections, drag or use arrow controls to reorder them, and link the claims each section addresses. The source shelf can be limited to evidence attached to those claims and then filtered further by relationship role or theme. Add selected excerpts to the section and write without leaving the evidence context. Use Copy Markdown when you want the outline in another writing tool.

6. Check project health

Review every nonzero check before treating the synthesis as complete. The Health tab identifies unscreened documents, included sources without excerpts, missing DOI or publication dates, excerpts without themes, claims without evidence, and orphaned excerpts. A zero confirms structural completeness for that check; it does not confirm that the interpretation itself is correct.

7. Generate and inspect a report

Select Synthesis report to review a consolidated representation of the protocol, screening, extraction, claims, and draft. The report can be saved as HTML. Before sharing, use the Health tab and manually check every substantive claim against its linked evidence.

Traceability supports judgment; it does not replace it.

Linked excerpts make reasoning inspectable, but you remain responsible for source quality, interpretation, methodological decisions, and final conclusions.

09

Save, focus, and recovery

Protect continuity across long research sessions without turning project management into a second project.

Save deliberately

The header status reports whether changes are saved, pending, or in error. Select Save or press Ctrl + S to flush current changes and create a recovery checkpoint. Manual checkpoints preserve graph and synthesis workspace state; they do not roll the underlying catalogue back to an earlier version.

Use the Research Support Center

Select the coffee-cup button in the header. Its four tabs help maintain continuity:

Focus lane
Build a temporary, reorderable queue of documents, excerpts, claims, or draft sections for the current session.
Attention
Review quality and continuity flags. Items clear when the underlying issue is addressed; dismissed items can return if it changes.
Session
Optionally track time or completed items, record breaks, and finish with a private handoff note and next starting point.
Recovery
Resume unfinished excerpt drafts and create or restore graph and synthesis checkpoints.

Work deliberately with each support tab

  • Focus lane: choose an item type, select an item, and add it to the queue. Use the arrows to set the working order and the checkboxes to mark progress.
  • Attention: open or resume the flagged record, correct the underlying condition, and let the item clear automatically. Dismiss only when no action is required.
  • Session: start an optional session, record breaks when useful, then summarize what changed and what should happen next before ending it.
  • Recovery: resume unfinished excerpt drafts by update time, or label a checkpoint so its purpose is recognizable later.

Resume after reopening

When resume prompts are enabled in Settings, Thematic can offer to reopen the previous project, workspace, document, excerpt, synthesis tab, and Library filter. Choose Resume to continue or Start elsewhere to dismiss the prompt.

Checkpoints are not a substitute for backups.

Export a .thematic bundle regularly and keep copies in a separate, appropriately protected location.

10

Export, backup, and sharing

Choose an output based on whether the recipient needs the project, the data, or a human-readable synthesis.

Export project data

  1. Open Export project and confirm the displayed document, excerpt, and theme counts match the intended project.
  2. Select the format that matches the recipient's needs; the export button updates to show the chosen file type.
  3. For a library archive, decide whether to include no source files, synthesis-used sources, or every available source.
  4. Choose a destination in the system dialog, then open and inspect the result before relying on it.

Select the download button in the header, use the command palette, or press Ctrl + Shift + E to open Export project. The summary shows the number of documents, excerpts, and themes before export.

FormatBest forContents
.thematicBackup, transfer, or collaboration in ThematicA self-contained portable project, including copies of available source PDFs and Markdown files.
.xlsxReview in Excel or another spreadsheet toolSeparate sheets for documents, excerpts, themes, and relationships; image excerpts are embedded.
.csvSimple interchange and analysisA flat table with one row per annotated excerpt. Image binary data is intentionally omitted.
.sqlite3Queries, scripts, and archival transferA relational copy of the catalogue, including image excerpt data.
.zipGeneral-purpose data archiveCatalogue JSON plus no sources, only sources used in the synthesis outline, or all available source files.
.html reportReading or sharing a synthesisA rendered synthesis report saved from the Synthesis workspace.

Recommended backup routine

  1. At the end of a substantial session, press Ctrl + S.
  2. Export a portable .thematic bundle.
  3. Name or store the bundle so the project and backup date are unambiguous.
  4. Keep at least one copy outside the computer that runs Thematic.
  5. Occasionally import a backup as a new project to confirm that it opens as expected.

Before sharing

  • Assume excerpts, notes, image regions, citations, screening decisions, and synthesis text may contain sensitive research material.
  • Remember that portable bundles can include complete source documents.
  • Use a data-only export when recipients do not need copyrighted or confidential source files.
  • Open the exported result and inspect it before sending or publishing it.
11

Settings and optional local AI

Adapt reading, graph, accessibility, citation, and assistance defaults to your workflow.

Select the gear button or press Ctrl + , to open Workbench settings.

Workspace defaults

Reading and notes

Choose plain text or Markdown + KaTeX, initial reader zoom, and default excerpt color.

Graph behavior

Set label visibility, default layout, initial zoom, node scaling, graph-note color, and theme or excerpt shapes.

Appearance

Choose an academic color scheme, coordinated font set, interface text size, and comfortable, compact, or presentation density.

Continuity

Enable resume prompts, quick excerpt capture, quiet break reminders, and optional session targets.

Online citation lookup

This feature is off unless enabled. When enabled, Thematic can detect an explicit DOI in imported PDFs, verify it through online DOI and Crossref services, and populate matching metadata. The optional contact email is included only in Crossref metadata requests. Leave the feature off when the project must not make those requests.

Local theme suggestions

Theme suggestions are optional and disabled by default. You can connect Thematic to an Ollama service or a local llama.cpp llama-server. Endpoints are expected on localhost; the usual defaults are port 11434 for Ollama and 8080 for llama.cpp. Suggestions are presented for review and are not saved until you accept them and save the excerpt.

Ollama

  1. Run Ollama and ensure the intended model is available.
  2. Enable Local theme suggestions.
  3. Choose Ollama, verify the localhost endpoint, and enter the model name.
  4. Save settings, open an excerpt, and select Theme suggestion.

llama.cpp

  1. Choose llama.cpp (GGUF) as the local service.
  2. Select or enter the llama-server executable and main GGUF model.
  3. Review the additional server arguments and localhost endpoint.
  4. For image suggestions, enable the image option and choose the matching multimodal projector GGUF.
Storage and network boundaries

The desktop catalogue is stored in SQLite on the computer, while original documents remain at their existing paths. Extracted text, annotations, and image excerpts enter the catalogue. Local-model suggestions use the configured localhost service; optional citation lookup is a separate online feature.

13

Troubleshooting

Start with the symptom, protect the project, and make the smallest corrective change.

Windows reports an unknown publisher

This is expected for the current unsigned installer. Confirm that it came from the official GitHub Release and verify its SHA-256 checksum against the value in the release notes. Do not proceed when the source or checksum is uncertain.

A source no longer opens

The original file may have been moved, renamed, disconnected, or deleted. Find the document in the Library and use its relink action to choose the new path. Relinking preserves the catalogue record and its excerpts.

An indexed folder is out of date

Use the Library's rescan action. This re-reads the folder catalogue while keeping interface preferences and existing analytic work.

An excerpt draft disappeared from the panel

Open the Research Support Center, choose Recovery, and look under Unfinished drafts. Select Resume to reopen one. Thematic retains a limited recent set, so save important excerpts promptly.

The graph is crowded or appears lost

Clear active filters, re-center the graph with Ctrl + Shift + R, and apply auto-layout with Ctrl + Shift + L. Reduce visible labels or filter by theme or document before arranging nodes manually.

Citation metadata was not found

Confirm that online citation lookup is enabled and that the computer can reach the metadata service. Check the DOI printed in the PDF, enter it in the document record, and retry Find metadata. When no reliable match exists, enter or import the metadata manually.

Local theme suggestions do not run

  • Confirm that the Ollama or llama.cpp service is running on the endpoint saved in Settings.
  • Verify the model name or GGUF path and the llama-server executable.
  • For image excerpts, confirm that visual suggestions are enabled and the multimodal projector matches the model.
  • Theme suggestions are optional; excerpts, themes, and synthesis work normally without them.

A portable project reports missing or conflicting files

Read the import preview and resolve every reported source before confirming. If you are repairing an existing project, create a fresh export first. Repair adds missing bundle state without intentionally replacing current edits, but a separate backup remains the safest recovery point.

Get further help

Search existing reports or open a new issue in the Thematic issue tracker. Include the app version, what you expected, what happened, and reproducible steps. Do not attach confidential source files or portable projects to a public issue.
